### B1. `$urandom(seed)` replay -- CLOSED (with NB1 on one clause)

Chapter, line 128: *"The first line is `$urandom(seed)` done as a bare
statement, twice, with nothing between: it replays the three values that
follow. The second is the same call with its result assigned to a variable
nothing reads, and it does not replay: the first call is removed as a dead
store ... and the second sequence begins with the first draw of the
well-formed pair, because only the second call survived. ... The fifth line
is the first measurement repeated after those thread reseeds, and it no
longer replays: on this release, once a process has reseeded itself,
`$urandom(seed)` in the thread that forked it does not reseed the generator

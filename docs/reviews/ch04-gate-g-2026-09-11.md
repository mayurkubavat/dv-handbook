## G1 detail — a quotation that is not in the source

Chapter, `:77`, in full:

> That is how a design can hang without time ever moving, and there is more
> than one way in. @sec-ch03 mentioned an `always` block with an *empty*
> sensitivity list, which never waits for anything and so runs again
> immediately. The form that catches people is subtler and needs a
> sensitivity list to work: a non-blocking assignment inside a combinational
> block assigns a variable that block is sensitive to, so the update
> retriggers the block, which schedules the assignment again, which
> retriggers it again. The reported symptom is the source's own headline for
> it: "the simulation locks up and time stops advancing"
> [@sutherland2007gotchas].

The source, fetched from the entry's own URL
(`http://sutherland-hdl.com/papers/2007-SNUG-SanJose_gotcha_again_paper.pdf`,
`pdftotext -layout`, `g2007.txt:334–337`):

```
2.4 Nonblocking assignments in combinational logic
Gotcha: My RTL simulation locks up and time stops advancing.
Synopsis: Nonblocking assignments in a combinational logic block can cause infinite loops that
lock up simulation.
```

```
$ grep -n -i 'locks up' g2007.txt
335:Gotcha: My RTL simulation locks up and time stops advancing.
358:There are actually two gotchas in the preceding example. One is that simulation locks up as soon
817:Gotcha: When I run simulation it either locks up or my combinational logic gets incorrect results.
```

The string "the simulation locks up" appears nowhere in the paper. Round F
(F-M2) measured the reproduced fragment as "seven words, verbatim" —
"simulation locks up and time stops advancing" — and asked for quotation
marks around them. The fix put the marks around those seven words plus a
leading "the", so the fragment is no longer verbatim, and the sentence that
introduces it ("the source's own headline") now makes a claim the source
refutes. This is the same pattern round F recorded for D4 → E1 → F1: a fix
that introduced the next round's finding in the same sentence.

Why blocking rather than minor: the book's rules make a direct quotation the
one form of borrowing that must be exact ("Direct quotation is limited to a
sentence or two, in quotation marks, with the citation on the same line"),
this round's brief asked specifically that each quotation from this paper be
checked verbatim, and a reader who opens the paper at §2.4 will not find the
quoted words. That the alteration is one function word does not change what
the quotation marks assert.

*Fix.* Either of:

> The reported symptom is the source's own headline for it: "My RTL
> simulation locks up and time stops advancing" [@sutherland2007gotchas].

or

> The reported symptom is the source's own headline for it — the
> "simulation locks up and time stops advancing" [@sutherland2007gotchas].

Then re-read the printed line against `g2007.txt:335`.

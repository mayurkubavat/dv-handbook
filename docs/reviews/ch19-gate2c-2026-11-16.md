## Blocking finding

**B1. Line 690 (and line 584): "or that every cycle passes through a
register in the sense of @sec-ch19-ag" admits circular proofs of false
lemmas.**

Line 690: "And a chain is circular when a lemma's proof assumes the
end-to-end property, or another lemma whose proof assumed it: draw which
proof assumed which property and check that the graph has no cycle, or
that every cycle passes through a register in the sense of @sec-ch19-ag."

The assume-guarantee argument of @sec-ch19-ag is sound because each block
is proved *on its own*, with its neighbor removed: the assumption then
constrains only the block's input, the register keeps that input from
reaching the block's output in the same cycle, and the block's own reset
value is checked with nothing assumed about it (that is why block A with
`RST1 = 1` is refuted at depth 1). Lemmas of a decomposition are proved
on the *same* design, and the tool applies an assumption in every cycle,
including the reset cycle and the cycle being checked. A register in the
loop then protects nothing: the assumed lemma can contradict the reset
state, or constrain the very state the asserted lemma reads, and the
proof goes through vacuously.

Measured (scratch, InFormal at the pinned build, `informal-kind`, 5 s): a
module with two registers, `a <= b; b <= a`, both reset to 1, which is
the `ag` ring with `RST1 = 1` in both blocks. The loop of dependence
passes through a register in each direction.

```
L1_A  a == 0, alone                    cex  depth 1
L1_A  a == 0, with b == 0 assumed      proven
L2_A  b == 0, with a == 0 assumed      proven     (cover rst_n: unreachable)
```

Both lemmas are false, each is "proven" under the other, and the proof
graph's only cycle passes through registers, so the chapter's exemption
accepts the pair. (Only a witness cover exposes it, which is worth one
clause in the fix.)

The same condition is missing from the assume-guarantee entry itself,
which is where the exemption points. Line 584: "Proofs, for safety
properties, when every loop of mutual dependence passes through a
register." The `ag` example proves each block alone (`design $f blk`), so
the example is sound, but the entry never says that this is required; a
reader who assumes `G_y` and asserts `G_x` on the flat ring with the reset
values above gets the table printed here.

Fix. Line 584, after "passes through a register": "and each block is
proved on its own, with its neighbor removed, so that the assumption
constrains only the block's inputs and nothing is assumed about its reset
state." Line 690, replace from "draw which proof assumed" with: "draw
which proof assumed which property and check that the graph has no
cycle. The circular form of @sec-ch19-ag is not an exception here: it is
sound because each block is proved alone and assumes only what arrives at
its inputs, while lemmas about one design are proved on the same state,
and two false lemmas about a ring of two registers, each reset to 1, are
each proven with the other assumed. Their witness covers are unreachable,
which is the only row that says so." The glossary entry "Decomposition
(property)" already states the right condition and needs no change.

## Teaching

The rewritten timer passage now teaches something true and portable: a
tool may evaluate a multi-cycle assumption late, here is the measurement
that shows it, write gap assumptions one cycle at a time. Separating it
from the prophecy trap makes both lessons sharper. The decomposition
entry's new sentence that lemmas implying the goal "are the aim, not a
defect" removes the contradiction round 1 found. B1 is the one place
where the chapter's soundness teaching would now lead a careful reader
into a false proof, and it is the chapter's subject; hence blocking.

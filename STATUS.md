- 2026-09-11 — **Unknown is not none.** In `clock_deps` a net the netlist cannot see into (black box, memory, undriven) depends on `UNKNOWN`, and an input carrying `UNKNOWN` at a gate is never control: a PLL output is a primary clock by the chapter's own definition. Dependencies are clock port *bits*, not names. A latch is state (its output depends on its enable and data, and stops the through-logic-alone walk), which is what makes the chapter's latch-based clock gate pass declared. Any `$` combinational cell passes. The walk is a worklist that includes register clock pins, so a 1200-stage ripple counter no longer recurses.
- 2026-09-11 — **The report lists every port read as gating control.** A clock that only ever appears gated is, to the netlist, an enable, and no completeness check can catch its omission from `--clock`; `ports_treated_as_control` in the clock tree (and one line in `read`) is the honest answer, so a reader who finds a clock in the list has found the declaration's mistake.
- 2026-09-11 — **Every spliced block asks for its lines to fit on the page.** `theme/include-code.lua` emits `\Needspace{n\baselineskip}` (n = lines + 3, capped at 18) before each included block in LaTeX output. - 2026-09-11 — **When a pass adds an example, re-read every paragraph that generalizes over "the examples".** The E1 fix shipped a fifth example and left "none of them declares a timescale" standing two paragraphs below it — a blocker the next review found on the first read.
- 2026-09-11 — **The clock-evidence heuristic is replaced by a definition, and the build-gate excuse requires a declaration.** Nine review rounds each found a netlist shape the evidence scored wrongly (a second clock on one port, a clock bus from a black box, a blend, a gate-built mux, a divider feeding a gate). The reviewer's own proof settled it: on `divblend.sv` a *misspelled* `--clock` gave the right answer and a correct one gave the wrong answer. Now: **undeclared**, a gate where more than one input could be a clock — a port or a register output — is reported undecided and fails; `same_clock_source` is never true without a declaration. **Declared**, `clock_deps` asks each gate input which declared clocks its value depends on: inputs reaching a clock through logic alone are the gate's clocks; an input depending on nothing or only on clocks the gate already has is control (an enable, or a divider of the same clock — one domain gated); an input depending on a clock the gate lacks is a blend (new domain). No shape is recognized. `--clock` is checked: a name that is not a port, or a list that omits a port driving a clock pin, is exit 2 — a partial declaration can only remove findings.
- 2026-09-11 — **The reset walk is not the clock walk.** It skipped a multiplexer's select, and Yosys builds an ordinary set/reset flop's CLR net as a mux whose select *is* the reset, so the reported source was `["const 0", "const 1"]`. Reset nets are walked as data cones; constants are not sources when a signal is.
- 2026-09-11 — **A latch is a destination.** The loop that constructs crossings only visited flip-flops, so eight bits into a transparent latch held open by another domain's enable reported as clean. `_latch_crossings` compares the data cone against the *enable's* domain.
- 2026-09-11 — **The human report wraps at 78 columns and puts every location on its own line.** The chapter prints it verbatim on a portrait page; three lines ran to 96 columns.
- 2026-09-11 — **Programming ligatures are off in every code listing, PDF and HTML.** JetBrains Mono renders `<=` as a single glyph, so `safe.sv` printed `count ≤ 8'h00;` directly under a sentence telling the reader to change four `<` characters, and verbatim simulator output was corrupted the same way — 233 occurrences book-wide. `RawFeature=-calt` in `_quarto.yml`'s `monofontoptions` (only `-calt`; `-liga` alone does not do it, and a comma inside `RawFeature={...}` breaks Quarto's option splitting), plus `font-variant-ligatures: none` on code in `theme/book.scss`. - 2026-09-10 — **`dvh --clock NAME` declares a clock, and without it a gate is undecided.** `clk & en` and `clk1 & clk2` are the same gate: in each, one input drives registers elsewhere and the other does not. Reading strong evidence for one input as evidence *against* the other made Plassan's *blending* — and a glitch-free clock multiplexer built from gates — read as "one clock, gated differently", exit 0 on an eight-bit unsynchronized crossing. Undeclared, such a gate is now reported undecided and fails; `--clock`, repeated per clock, makes a declared name the only clock evidence and a gated design then passes cleanly. This is the chapter's own thesis (the relationship between clocks is a property of the specification) arriving as a command-line flag.
- 2026-09-10 — **`keep_hierarchy` is stripped before `flatten`, and `load_flat` raises if anything is still instantiated.** Yosys honors the attribute, so a CDC wrapper marked with it left every register in a module the walks never looked at: 0 domains, 0 crossings, exit 0. Their content goes into the chapter text and their citations into `refs.bib`; third-party links are the only references. - The publication rule is broader than the mention hook: any description of AI-assisted authoring (roles, hooks, reviewers) is out, even with no names. Reviewer prompt now checks for it explicitly; keep doing so.
- Ch.34 (and Part VII generally): concept chapters, theory + block diagrams + SW-practice parallels; cite evidence where a number is claimed but do not survey DV articles or build the chapter around runnable agent code (author, 2026-09-06).
- Run `research-topic` BEFORE `draft-chapter`, never during: the drafting lock blocks research writes (a research subagent had to park its note in scratch on 2026-09-06). Sequence is research → outline → draft.
- Attribution: primary sources for every fact, short attributed quotations only, redraw never reproduce, credit discoverers of named bugs (author, 2026-09-06). Written into AGENTS.md.
- Agent configuration (`.claude/` and the one-line stub that imports AGENTS.md) never goes to the remote; it is gitignored. Keep a private backup if it matters.
- No mention of AI assistance, its vendor, or its tooling anywhere in the repo, including commit messages (decided 2026-09-06). Factual references to AI models as book subject matter are fine.
- Keep every included source file ≤ 80 columns (≈ 83 fit at `\small` mono in the 7×10 trim); comment rulers exactly 72 cols. `breaklines` is only the safety net.
- Makefile recipes need real tabs; listings show 4 spaces (Pitfall callout in the build appendix explains this).

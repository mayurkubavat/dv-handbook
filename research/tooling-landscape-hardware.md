# Tooling landscape survey: hardware side

Scope: open (and a few labelled vendor) tools across RTL parsing, simulation, coverage, waveforms, formal, MCP/agent wrappers, debug data sources, spec tooling, build/CI. Each row records what an agent could do with the tool through a tool interface (CLI, Python API, LSP, library). URLs were checked with curl on 2026-09-07 unless marked "unverified".

Maturity scale: **production** (widely used, multi-year, releases), **stable** (usable, active, smaller community), **experimental** (young, single-maintainer, or research), **dormant** (no meaningful activity for 2+ years).
